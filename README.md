# Табак-міксер 💨

Маленька веб-апка, яка за секунди обирає мікс із двох табаків для кальяну (50/50), щоб не сидіти й не думати.

## Що вміє
- **Каталог** — 100-грамові табаки Gedonist, 420, Unity та Custom з [aladin-kyiv.com](https://aladin-kyiv.com/ua/tabak-dlya-kalyana/): смак, міцність, солодкість/кислинка/свіжість, ціна, наявність, посилання на магазин.
- **Мої оцінки** — 1–5★ і коментар до кожного табаку, позначка 🏠 «є вдома».
- **Топ** — улюблені смаки (4–5★), улюблені мікси (👍) і ті, що не сподобались (1–2★ — більше не пропонуються).
- **Мікс** — обираєш, з чого міксувати (🏠 вдома / ⭐ мій топ / 🛒 усе, що є в магазині) і настрій (Свіже / Солодке / Кисле / Десертне / Фруктове).
  Розумний рандом підбирає пари, що добре поєднуються, враховує оцінки й не повторює нещодавні мікси.
- **Історія** — «Курю цей!» записує мікс, 👍/👎 впливають на майбутні пропозиції.
- Працює офлайн, додається на головний екран телефона. Особисті дані зберігаються тільки на телефоні (є бекап у файл).

## Оновлення каталогу
```bash
python3 scraper/aladin.py
```
Скрипт обходить категорії 100 г потрібних брендів (з паузою між запитами) і перезаписує `data/catalog.json`.
Категорії смаку визначаються за полем «Смак» з сайту — таблиця в `scraper/flavor_tags.py`.
Якщо з'являться нові інгредієнти, скрипт їх покаже — їх варто додати в таблицю.

## Як відкрити на телефоні
GitHub Pages: Settings → Pages → Source: `Deploy from a branch`, гілка `main`, тека `/ (root)`.
Адреса: `https://<логін>.github.io/tabak/`

- **iPhone (Safari):** Поділитися → «На початковий екран».
- **Android (Chrome):** меню ⋮ → «Додати на головний екран».

## Локальний запуск
```bash
python3 -m http.server 8000
```
Потім відкрий http://localhost:8000

## Структура
- `index.html`, `style.css` — інтерфейс
- `js/app.js` — екрани й кнопки
- `js/catalog.js` — завантаження каталогу й поєднання з особистими даними
- `js/store.js` — оцінки, коментарі, «вдома», історія, бекап
- `js/mixer.js` — логіка вибору міксу
- `js/flavors.js` — категорії смаків, таблиця сумісності, настрої
- `data/catalog.json` — каталог табаків (генерується скрейпером)
- `scraper/` — збір каталогу з магазину
- `sw.js`, `manifest.webmanifest`, `icons/` — офлайн-режим і встановлення на телефон
