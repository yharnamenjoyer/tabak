# Табак-міксер 💨

Маленька веб-апка, яка за секунди обирає мікс із двох табаків для кальяну (50/50), щоб не сидіти й не думати.

## Що вміє
- **Колекція** — табаки, що є вдома: смак, бренд, категорії смаку, міцність, «є / закінчився».
- **Розумний рандом** — підбирає пари, що добре поєднуються за смаком, не повторює те, що курив недавно, і враховує твої оцінки.
- **Рандом за настроєм** — Свіже / Солодке / Кисле / Десертне / Фруктове.
- **Історія та оцінки** — «Курю цей!» записує мікс, 👍/👎 впливають на майбутні пропозиції.
- Працює офлайн, додається на головний екран телефона як звичайна апка.
- Дані зберігаються тільки на телефоні. Для бекапу є «Колекція → Бекап даних».

## Як відкрити на телефоні
Апка хоститься безкоштовно на GitHub Pages: Settings → Pages → Source: `Deploy from a branch`, гілка `main`, тека `/ (root)`.
Адреса буде `https://<логін>.github.io/tabak/`.

- **iPhone (Safari):** Поділитися → «На початковий екран».
- **Android (Chrome):** меню ⋮ → «Додати на головний екран».

## Локальний запуск
```bash
python3 -m http.server 8000
```
Потім відкрий http://localhost:8000

## Структура
- `index.html`, `style.css` — інтерфейс
- `js/flavors.js` — категорії смаків, таблиця сумісності, настрої
- `js/mixer.js` — логіка вибору міксу
- `js/store.js` — збереження даних і бекап
- `js/app.js` — екрани й кнопки
- `sw.js`, `manifest.webmanifest`, `icons/` — офлайн-режим і встановлення на телефон
